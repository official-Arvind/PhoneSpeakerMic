Choose Your Mode

One App. Three Modes.

Pick exactly what you need before connecting. The server only activates the required streams — zero wasted processing.

🎤

MIC Only

Phone microphone streams directly to your PC as a virtual input device. Perfect for Discord, Zoom, Teams, OBS.

0x01 Protocol
  • Hardware AEC enabled
  • Noise suppressor active
  • Routes to VB-Audio CABLE
🔊

SPEAKER Only

Your PC's system audio loopback streams to the phone speaker. Use your phone as a wireless monitor speaker.

0x02 Protocol
  • Loopback capture (WASAPI)
  • Auto stereo → mono mix
  • Laptop speakers auto-mute
🔄

BOTH

Full bidirectional bridge. Phone mic goes to PC, PC audio goes to phone. Complete audio device replacement.

0x03 Protocol
  • Two independent streams
  • Dual callback pipelines
  • Full mode on single socket

What's Inside

Precision-Engineered. Every Detail.

🎙️

Hardware AEC

Acoustic Echo Cancellation runs directly on your phone's dedicated audio DSP — zero CPU overhead, studio-grade mic quality.

🔇

Auto Speaker Mute

Windows Core Audio API (pycaw) mutes your laptop speakers the instant the phone connects. Restores exact volume on disconnect.

🔌

USB ADB Mode

Skip WiFi entirely. Plug a USB cable, server runs adb reverse automatically — sub-7ms latency guaranteed.

⚡

Callback Audio

Python's blocking stream.read() is replaced with hardware-timed callbacks. The OS audio clock drives everything.

🧵

Thread Priority

THREAD_PRIORITY_AUDIO on Android + HIGH_PRIORITY_CLASS on Windows. Scheduler never deprioritizes audio.

🔒

100% Private

Direct TCP socket on your local network. Zero internet. Zero accounts. Zero analytics. Every byte stays in your home.

🧹

Noise Suppressor

Android's hardware noise suppressor runs alongside AEC — keyboard clicks, fans, background noise: all filtered out.

🛡️

Buffer Bloat Guard

Server caps the ring buffer at 20ms. Old data is dropped aggressively — no artificial delay builds up over time.

Get Started

Up in 3 Steps.

01

PC Setup

Install Python 3.10+ and run one command:

pip install pyaudiowpatch numpy pycaw comtypes
python pc_server.py

Optional: Install VB-Audio Virtual Cable to use phone mic in Zoom/Discord as a proper device.

02

Install the App

Download the APK from Releases or build from source in Android Studio.

⬇ Download APK

Grant microphone permission when prompted.

03

Connect & Stream

Same WiFi network → pick your mode → enter PC IP → tap WIFI LINK.

Your laptop speakers auto-mute. Phone takes over. Done.

For lowest latency: plug USB cable → tap USB MODE instead.
